# Vesper X - Aerospace Luxury E-Commerce Ecosystem

Submitted for **VibeForge 1.0 Hackathon** by Team **Runtime Terrors**.

## 🚀 About the Project

Vesper X is a futuristic, aerospace-grade luxury tech ecosystem designed to redefine modern e-commerce through sleek design, seamless cross-device responsiveness, and high-performance architecture.

## ✨ Key Features

- **Advanced Product Comparison:** Compare specifications side-by-side with ease.

- **Dynamic Currency Support:** Instant switching between USD ($) and INR (₹).

- **Real-Time Order Tracking:** Track order statuses and shipping updates seamlessly.

- **Fully Responsive UI:** Optimized mobile hamburger menu `☰`) and adaptive layouts.

- **Secure Authentication & Cart:** Smooth user journey from secure sign-in to checkout.

## 🛠️ Tech Stack

- **Frontend:** Next.js (App Router), React, TypeScript

- **Styling:** Tailwind CSS

- **State Management:** React Context API

- **Deployment:** Vercel
